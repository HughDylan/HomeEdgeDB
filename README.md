# HomeEdgeDB — 基于 FlashDB 的智能家居边缘网关

> STM32F103C8T6 + W25Q64(8MB) + FlashDB（KVDB + TSDB）
> 节点数据上报 → 帧解析 → 时序落盘 → `dump` 回溯，断电不丢

## 一、项目简介

以 STM32F103C8T6 为核心、外挂 8MB SPI Flash（W25Q64）的智能家居边缘网关。
网关接收节点上报的环境数据（温度 / 湿度 / 光照 / 人体感应 / 继电器状态），
解析后以时序数据（TSDB）持久化到本地，并可通过串口指令回溯历史记录；
配置项以键值（KVDB）方式独立存储，与历史数据分区隔离。

- 节点侧当前由串口模拟上报，后续接入 nRF24L01 组成多节点无线网络；
- 存储侧通过 FAL（Flash 抽象层）解耦，更换存储介质时业务代码无需改动。

## 二、系统架构（四层）

| 层 | 组成 | 职责 |
|---|---|---|
| 感知层 | 热敏电阻、光敏电阻、DHT22 | 采集环境数据（当前以串口字符串模拟） |
| 网关层 | `protocol.c` | ASCII 帧解析、字段完整性校验 |
| 存储层 | `app_fdb.c` + FAL + FlashDB + W25Q64 | KVDB 存配置，TSDB 存历史 |
| 展示层 | OLED + 串口 | 实时显示与历史回溯 |

## 三、技术栈

- 主控：STM32F103C8T6（ARM Cortex-M3，72MHz）
- 存储：W25Q64（8MB SPI Flash）+ FAL + FlashDB v2.x
- 通信：UART（自定义 ASCII 帧）、SPI、I2C
- 开发：Keil MDK（ARM Compiler 5）+ STM32 标准外设库

## 四、数据布局

| 分区 | 偏移 | 大小 | 用途 |
|---|---|---|---|
| `fdb_kvdb1` | 0 | 512 KB | 联动阈值、上报周期、节点表 |
| `fdb_tsdb1` | 512 KB | 7.5 MB | 按时间戳存储的采样记录 |

KV 数据量小但会被频繁改写，因此单独划小分区；时序数据只追加，占大头。
